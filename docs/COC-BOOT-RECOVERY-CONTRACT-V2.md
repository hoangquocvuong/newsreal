# CoC Boot Recovery Contract V2

The public Clash of Clans showroom must boot only after the full game runtime and sample-data constants have initialized. The game demo may not depend on the shared real-estate tenant to decide which DOM to paint. If rendering fails, the transport BDS shell must never be exposed. A diagnostic is stored in `window.__NR_GAME_BOOT_ERROR__` and a CoC-safe emergency shell is rendered.

Contract: `game-post-script-safe-boot-v1`.
