# CoC Article Sidebar Contract V1

Desktop article sidebar must remain visible below the sticky CoC navigation and may not be covered while the page scrolls. The sidebar contains: Base Link CTA, Base Information (group, level, purpose/district, year, style, defense), and a short usage guide. It is not given a private scroll area.

On mobile (<=900px), the desktop sidebar is hidden because Copy Base and Donate are provided by the article bottom dock. This avoids duplicate CTAs and preserves viewport space.
