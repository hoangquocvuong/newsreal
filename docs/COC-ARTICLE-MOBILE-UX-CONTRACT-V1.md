# CoC Article Mobile UX Contract V1

- Mobile article has one fixed bottom action dock only: Copy Base + Donate.
- Floating circular Donate is hidden only on article detail; it remains on other Game pages.
- In-content/sidebar Copy Base link is hidden on mobile to prevent duplicate CTAs.
- Article body spans the same mobile content width as the article/image card.
- Mobile menu Saved Bases has no decorative leading bookmark icon.
- Related Bases are strict same Group + same Level. A TH17 article may only recommend TH17 records; purpose match is preferred inside that level.
