# Commerce Clean Slate V18

- Replaces the V17 marketplace storefront markup and visual system with a new clean-slate storefront.
- New design identity: editorial commerce, warm neutral hero, asymmetric promotional cards, rounded search/cart, category tiles, minimal product catalog.
- No V17 `market17`, `m17-*`, NOVASHOP-specific markup, or Smartphone Pro hero markup remains in the Commerce renderer.
- Keeps existing commerce API, cart, checkout, pagination/filter functions, tenant/trial routing, and `universal_commerce_5` contract.
- Demo / Trial / Live continue to enter the same `renderCommerceStore()`.
