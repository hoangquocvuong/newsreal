# V12 – Lion Adaptive Editor

The Lion Dance editor now adapts its fields to the selected category.

- Gói múa lân / Múa rồng / Trống hội: commercial/service fields remain available.
- Sự kiện đã thực hiện: only event date, location and optional video metadata are shown.
- Tin hoạt động / Kiến thức & phong tục: service pricing and package-spec fields are hidden; the normal title, images and rich-content editor remain.
- Switching category re-renders the schema immediately while preserving common values when applicable.
- CRUD, sample tombstones, tenant resolution and Trial mapping are unchanged.
