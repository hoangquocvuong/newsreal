# Commerce Simple Admin V26
- Product publishing reduced to name, category, price, images, stock, one description and Publish.
- SKU and raw image/gallery URLs are hidden and generated automatically.
- Default categories load from the tenant API; retry state is explicit if loading fails.
- Shop owners can create a category directly beside the category selector.
- Advanced attributes/variants are optional and collapsed.
- Publish requires a category and shows a clear success message including the destination category.
- The product list below shows image, category, price, stock and live/hidden state.
