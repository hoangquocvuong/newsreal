# V16 — New Commerce Template

- Replaces the old Commerce presentation contract with one storefront renderer for Demo, Trial and Live.
- Deterministic starter catalog and standard beginner-friendly categories for every new Commerce site.
- Admin product workflow gives an explicit success state and clear next actions after publishing.
- Product schema remains shared with storefront, related products, cart and checkout.
- Keeps 8 products per page and 2-column mobile catalog.
- Does not modify trial tenant resolution.
