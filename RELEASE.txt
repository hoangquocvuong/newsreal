NEWSREAL V20.9.0 — CoC Mobile-first UX V2

- Keeps the V20.8.9 CoC community architecture, hero showcase, local-first Saved and universal template contracts.
- Removes the fixed mobile bottom navigation completely.
- Adds a compact sticky mobile header with a three-line hamburger menu that drops down from the top without covering the full screen.
- Mobile menu only exposes working routes/actions: Home, Browse Bases, TH, BH, CH, Saved, About and Privacy.
- Donate header CTA now uses a clearly different green treatment from the orange Add Base CTA.
- Floating Donate remains a compact circular coffee button.
- Mobile base filters collapse to a one-line active-filter summary and open in a compact 74vh drawer with independent scrolling, Reset and View Results actions.
- Filter changes continue to use History API and now return focus directly to the Results section.
- Last Hall/filter preference is stored locally and used by Browse Bases on the next visit.
- Mobile result cards use a single-column list layout with larger image area and clearer tap targets.
- Mobile detail adds a persistent Copy Base dock while keeping article description visible.
- Saving a base now shows a short accessible toast: “Base đã được lưu”; removing shows “Base đã được bỏ khỏi Saved”.
- Saved state remains local-first and requires no Firebase connection.
- No database migration required.
